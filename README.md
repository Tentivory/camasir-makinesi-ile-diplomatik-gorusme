# Çamaşır Makinesi ile Diplomatik Görüşme

> Resmi uyari: Bu yazilim Birlesmis Milletler Camaşır Alt Komitesi tarafindan henuz taninmamistir. Taninmama, taninmadiginin taninmasidir.

## Nedir bu?

Dunyada baris yoksa sebep bellidir: kimse **600 devir/dakika** hizinda donen bir makineyle masaya oturmamistir.

Bu proje, evdeki beyaz esyanizi egemen bir devlet gibi tanir. Spin cycle veto hakki sayilir. Durulama turu ise güven artirici tedbirdir. Kapak acilirsa ateşkes bozulur.

## Kurulum

```bash
python3 diplomasi.py
```

Baska bagimlilik yoktur. Cunku diplomasi bagimlilik kabul etmez. (Su ve elektrik hariç.)

## Protokol Kurallari

1. Makineye "sen sadece bir cihazsin" demek savas nedenidir.
2. "Kisa program" teklifi aşağilayici bulunur.
3. Yumusatici eklemek rüşvettir ama kabul edilir.
4. Camasir toplanmadan gorusme baslamaz.
5. Copilot ile yazismak serbesttir; makine onu "dis istihbarat" olarak kaydeder.

## Ornek Cikti

Program calistiginda makine sizi kabul eder, reddeder ya da "su basinci yetersiz" bahanesiyle sureyi uzatir. Bu, gercek diplomasiden farksizdir.

## Gizlilik
